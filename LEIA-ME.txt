COMO USAR NO GITHUB PAGES
1. Envie TODOS os arquivos para a raiz do mesmo repositório.
2. O GitHub Pages continua apontando para a branch principal e /(raiz).
3. O endereço principal abrirá index.html.
4. Cada grupo poderá ser aberto pela página inicial.
